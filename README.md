# ОГЭ / 09 — интерактивная геометрия для 9 класса

Учебный сайт для уроков и самостоятельной практики. Это статический сайт на HTML, CSS и JavaScript: сборка и установка пакетов не нужны.

## Страницы сайта

- `index.html` — главная с кратким описанием курса и переходами к разделам.
- `topics.html` — каталог тринадцати тематических блоков.
- `practice.html` — квизы по выбранной теме, три случайных режима или весь курс.
- `journal.html` — импорт отчётов учеников, статистика класса и экспорт сводки в CSV.
- `about.html` — программа курса и инструкция ученику и учителю.
- `assets/` — общие стили, логика квизов и банк заданий. Папку нужно загружать вместе со страницами.

## Что внутри

- 13 тем и 133 вопроса: треугольники, подобие, тригонометрия, четырёхугольники, окружности, площади, клетчатая бумага, углы и параллельные прямые, координаты, векторы, геометрические утверждения, движения и симметрия.
- Дополнительные оригинальные задачи в форматах геометрических заданий первой части материалов ОГЭ 2027 года; к каждому заданию есть схема и пояснение после ответа.
- Три случайных режима на 7, 15 и 30 вопросов. Внутри одной тренировки вопросы не повторяются и распределяются по разным темам.
- Авторские тренировочные задания в стиле геометрических линий ОГЭ: длины и углы, площади, клетчатая бумага и теория.
- После каждого ответа появляется пояснение с формулой или свойством; при ошибке показывается правильный вариант.
- В конце ученик видит правильные ответы, ошибки, процент и результат по каждой теме.
- Ученик может скачать персональный JSON-отчёт, а учитель — загрузить сразу несколько отчётов в журнал класса.
- Журнал показывает среднюю точность, число ошибок, трудные темы и отдельные результаты учеников; сводку можно скачать в CSV и открыть в Excel.
- Лучшие результаты и импортированный журнал сохраняются в браузере на текущем устройстве.
- Адаптивная верстка, удобное меню на телефоне, анимации, клавиатурная навигация и поддержка настройки уменьшения анимации.

## Сбор результатов класса

Если ученики по очереди проходят квиз на одном устройстве в одном браузере, сайт сам добавит результаты в журнал.

Если каждый ученик работает на своём телефоне или компьютере:

1. Ученик проходит квиз, указывает имя и нажимает **Скачать отчёт для учителя**.
2. Ученик отправляет скачанный файл `.json` учителю удобным способом.
3. Учитель открывает страницу **Журнал** и нажимает **Импортировать отчёты**. Можно выбрать сразу несколько файлов.
4. Журнал покажет результаты по ученикам и темам. Кнопка **Скачать сводку CSV** сохранит таблицу для Excel.

Чтобы начать сбор заново, откройте страницу **Журнал**, нажмите **Очистить журнал** и введите пароль `110987`. Удалятся все отчёты, сохранённые или импортированные в этом браузере; прогресс по темам останется.

Отчёты не отправляются автоматически: ученики передают файлы учителю вручную. Импортированный журнал хранится в браузере учителя; общего сервера у сайта нет. Так как сайт статический, парольная форма защищает от случайного сброса, но пароль записан в JavaScript-коде сайта и не является надёжной защитой от пользователя, который умеет просматривать его исходники.

## Быстрый запуск на компьютере

Откройте `index.html` в браузере. Все HTML-страницы и папка `assets/` должны находиться рядом, как в проекте. Для показа на уроке можно вывести браузер на экран.

## Публикация на GitHub Pages

Загружайте в репозиторий все пять HTML-файлов и папку `assets/`, сохраняя структуру проекта. Если хотите, добавьте `README.md`.

1. Создайте на GitHub новый репозиторий. Для бесплатного GitHub Pages выберите публичный репозиторий.
2. Загрузите `index.html`, `topics.html`, `practice.html`, `journal.html`, `about.html` и папку `assets/` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В разделе **Branch** укажите `main` и папку `/(root)`, затем нажмите **Save**.
6. После публикации ссылка появится на странице **Settings → Pages**. Отправьте ученикам общий адрес сайта — они смогут переходить между страницами через меню.

Подробная инструкция: [создание сайта GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) и [выбор ветки и папки публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
